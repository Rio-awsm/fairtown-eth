# C 0.1 Foundation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** One pnpm monorepo with the shared package `@fairtown/shared`, a doctor framework, root scripts and repo records, so S1 0.1, S2 0.1 and S3 0.1 can start (C 0.1 in `03_BUILD_GUIDE_4_COMBINE.md`).

**Architecture:** A pnpm 9 workspace (`packages/*`, `services/*`, `apps/*`, `scripts`) with a version catalog, so viem and zod each have one version. `@fairtown/shared` ships TypeScript source, no build step; tsx, Vite and Bun import it directly. Every wire shape is a zod schema with its type inferred from it, so relay, services and web validate against the same definition. The doctor is a small check registry in `scripts/`; streams add their own rows in their 0.1 steps.

**Tech stack:** pnpm 9.15.9, Node 22.10+, TypeScript 5.9.3, viem 2.57.x, zod 4.6.x, Vitest 4.1.x, tsx 4.x, ESLint 10 with typescript-eslint 8, Prettier 3, dotenv and dotenv-expand.

**Commits:** Claude never commits. Each "Commit" step below means: stop, list the changed files and the suggested message, and the user commits.

**Source docs:** `../fairtown-docs/03_01_INTEGRATION_CONTRACT.md` sections 1, 4, 5, 6, 8, 9, 11, 12, 14 and 15; `03_00_START_HERE.md` (CLAUDE.md template, D-00 to D-27); `MILESTONE_SYNC.md` (one-time repo setup).

```ts
import { parseUnits } from "viem"
import { z } from "zod"

export const Q96 = 2n ** 96n
export const UNIT = 10n ** 18n
export const toQ96 = (perUnit: bigint) => (perUnit * Q96) / UNIT
export const fromQ96 = (q: bigint) => (q * UNIT) / Q96
export const tickFor = (floorQ96: bigint) => (floorQ96 / 100n > 2n ? floorQ96 / 100n : 2n)
export const floorToTick = (q: bigint, tick: bigint) => (q / tick) * tick
export const ceilToTick = (q: bigint, tick: bigint) => ((q + tick - 1n) / tick) * tick
export const toBase = (amount: string) => parseUnits(amount, 6)
export const splitPayout = (raised: bigint, feeBps: bigint, advanceBps: bigint) => {
  const fee = (raised * feeBps) / 10000n
  const net = raised - fee
  const advance = (net * advanceBps) / 10000n
  return { fee, advance, held: net - advance }
}

export const Dec = z.string().regex(/^\d+$/)
```

**Step 4: Write `doctor/core.ts`**

```ts
export type Status = "ok" | "warn" | "fail"
export type Owner = "shared" | "S1" | "S2" | "S3"
export type Env = Record<string, string | undefined>
export type Ctx = { env: Env; envFileFound: boolean; versions: { node: string; pnpm: string | null } }
export type Result = { status: Status; detail: string }
export type Check = { id: string; owner: Owner; title: string; run: (ctx: Ctx) => Result | Promise<Result> }
export type Row = Pick<Check, "id" | "owner" | "title"> & Result

export async function runChecks(checks: Check[], ctx: Ctx): Promise<Row[]> {
  const rows: Row[] = []
  for (const c of checks) {
    let r: Result
    try {
      r = await c.run(ctx)
    } catch (e) {
      r = { status: "fail", detail: e instanceof Error ? e.message : String(e) }
    }
    rows.push({ id: c.id, owner: c.owner, title: c.title, ...r })
  }
  return rows
}

export const exitCode = (rows: Pick<Row, "status">[]) => (rows.some((r) => r.status === "fail") ? 1 : 0)

export const formatRows = (rows: Row[]) =>
  rows.map((r) => `${`[${r.status}]`.padEnd(7)} ${r.owner.padEnd(6)} ${r.id.padEnd(16)} ${r.detail}`).join("\n")

export function atLeast(version: string, min: string): boolean {
  const parse = (v: string) => v.replace(/^v/, "").split(".").map((n) => Number.parseInt(n, 10) || 0)
  const [a, b] = [parse(version), parse(min)]
  for (let i = 0; i < 3; i++) if ((a[i] ?? 0) !== (b[i] ?? 0)) return (a[i] ?? 0) > (b[i] ?? 0)
  return true
}
```

import { existsSync, readFileSync } from "node:fs"
import { parse } from "dotenv"
import { expand } from "dotenv-expand"
import type { Env } from "./core"

export function loadEnv(file: string): { env: Env; found: boolean } {
  if (!existsSync(file)) return { env: { ...process.env }, found: false }
  const fromFile = parse(readFileSync(file, "utf8"))
  const merged: Env = { ...fromFile, ...process.env }
  const { parsed } = expand({ parsed: merged as Record<string, string>, processEnv: {} })
  return { env: parsed ?? merged, found: true }
}
